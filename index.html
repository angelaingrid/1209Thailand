DAY 1 2026/12/09 (三)
抵達曼谷・在地夜生活

高雄小港機場 → 曼谷素萬那普機場 → 最接地氣 Save One Go 夜市

今日於高雄小港機場集合搭乘中華航空直飛天使之城曼谷。抵達後專車前往曼谷近年超人氣的在地人夜市 Save One Go Market，這裡匯集了道地泰式平價小吃、炭烤海鮮、泰式奶茶與潮流服飾，物價親民、氛圍輕鬆，是第一晚體驗曼谷夜生活與大啖美食的最佳去處！

早餐：敬請自理
午餐：機上簡餐
晚餐：樂來順或文華 中泰式合菜 (餐標 THB 350)
住宿：Avani Sukhumvit Bangkok Hotel 或同級
DAY 2 2026/12/10 (四)
皇室經典・河畔晚宴

大皇宮與鄭王廟 → ICONSIAM 室內水上市場 → 河畔遊船晚宴

  • • 大皇宮與鄭王廟：參觀匯聚泰國皇室建築藝術巔峰的金碧輝煌宮殿；隨後造訪擁有「泰國艾菲爾鐵塔」美譽的鄭王廟（黎明寺），純白佛塔鑲嵌彩色陶瓷片，壯麗非凡。
  • • ICONSIAM 暹羅天地（室內水上市場）：曼谷頂級河岸地標百貨！特別安排逛逛冷氣開放的「SOOKSIAM 室內水上市場」，將泰國77府傳統水上市集搬進室內，乾淨舒適又好拍。
  • • 昭披耶公主號遊船晚宴：夜幕低垂時搭乘豪華遊輪夜遊昭披耶河，在現場樂團演奏與微風中享用豐盛自助餐，欣賞兩岸大皇宮與鄭王廟點燈夜景。
早餐：飯店內用
午餐：方便逛街 敬請自理
晚餐：昭披耶公主號自助餐 (餐標 THB 750)
住宿：Avani Sukhumvit Bangkok Hotel 或同級
DAY 3 2026/12/11 (五)
大城古都・泰服體驗

大城世界遺產 → 瑪哈泰寺(樹中佛頭) → 柴瓦塔那蘭寺+泰服體驗 → 大城大頭蝦市場 → 邦巴茵夏宮 → Big C 超市大採購

  • • 瑪哈泰寺（樹中佛頭）：大城最著名的奇觀，受菩提樹根溫柔包覆的慈祥佛頭，展現歷史與自然交織的震撼之美。
  • • 柴瓦塔那蘭寺＋泰服體驗：換上華麗典雅的傳統泰服，漫步於高棉風格的紅磚佛塔群間，輕鬆拍出穿越時空的皇室大片！
  • • 大城大頭蝦市場＆邦巴茵夏宮：午餐自理品嚐大城最著名的現烤爆膏大頭蝦；午後走訪融合泰式、中式與歐式建築的皇室避暑行宮「邦巴茵夏宮」，晚上前往 Big C 超市盡情採買伴手禮。
※ 註：參觀樹中佛如欲拍照留念，提醒您影中人身高不可高於佛頭，以免對神明造成不敬！
早餐：飯店內用
午餐：方便逛街 敬請自理
晚餐：方便逛街 敬請自理

DAY 4 2026/12/12 (六)
水上市集・網美泡泡屋

丹能水上市場(含船) → 鐵道市場 → 網美泡泡屋(含一杯飲料) → 四面佛祈福 → 中央百貨商圈

  • • 丹能莎朵水上市場（含手搖船）：搭乘傳統手搖船穿梭於熱鬧的運河水道，體驗與戴斗笠的船家交易熱帶水果與船麵的道地樂趣。
  • • 美功鐵道市場＆網美泡泡屋：親眼見證火車鳴笛緩緩駛過、攤販瞬間收起遮陽棚架的奇景；午後造訪夢幻水上漂浮「網美泡泡屋咖啡廳」，每人贈送一杯清涼飲料拍照打卡。
  • • 四面佛＆中央百貨商圈：返回曼谷市中心前往香火鼎盛的四面佛祈福，並逛逛亞洲最大購物中心之一的 Central World 商圈。
※ 註：菜市場鐵路火車之旅，常有誤點，敬請耐心等候。
早餐：飯店內用
午餐：泰式風味餐 (餐標 THB 350)
晚餐：Savoey Mercury分店 (代訂位/自點自付)
住宿：Avani Sukhumvit Bangkok Hotel 或同級

週末市集・滿載而歸

洽圖洽週末市集 (Chatuchak) → 曼谷國際機場 → 高雄小港機場

把握最後一天週日黃金時段，前往僅在週末營業的全球最大市集之一 洽圖洽週末市集 (Chatuchak Weekend Market)！擁有超過 15,000 個攤位，從設計師文創小物、香氛精油、藤編包到消暑椰子冰淇淋、手標泰式奶茶應有盡有，讓您在返台前滿載而歸！午後專車前往曼谷機場搭機返回高雄。

❖ 泰國入境與行前必讀提醒

重要必看
泰國電子入境卡申報（TDAC） 出發前必填

入境泰國前需事先於線上完成泰國數位入境卡（Thailand Digital Arrival Card, TDAC）申報，請務必於抵達泰國前 72 小時（3天）內上網填寫：

• 準備資料：護照個人資料頁、去回程航班資訊（CI839 / CI840）、住宿飯店名稱（Avani Sukhumvit Bangkok Hotel）。
• 填寫完成後：系統會產生一組 QR Code 確認信（亦會寄至您的 Email），請務必手機截圖保存或列印出來，於曼谷機場通關時出示給移民官查驗。
• 完全免費：官方網站申報無需任何費用，請勿點擊來路不明之付費代辦廣告網站。
前往泰國移民局 TDAC 官方申報網站

入境海關與攜帶現金提醒

泰國海關隨機抽查財力：
入境泰國每人須準備 20,000 泰銖、每個家庭 40,000 泰銖（等值美金、台幣現金亦可，不可用信用卡代替），以備海關人員隨機抽查。

• 攜帶現金上限：出入境各國攜帶現金請勿超過等值台幣拾萬元，超出部分請依規定申報。

行李重量與安檢規定

託運行李 每人 1 件 / 限重 23 公斤

中華航空團體機票可免費託運 1 件 23 公斤行李。液體類（超過100ml）、噴霧、剪刀、指甲刀、自拍棒（超過25cm）及傘具請放置於託運行李中。

手提隨身行李（電池嚴禁託運） 限重 7 公斤

手機電池、相機電池、行動電源（務必標示清晰容量 Wh/mAh）、藍牙耳機充電盒及打火機（限1個），務必放置於隨身行李中攜帶上機，嚴禁託運！

導遊、司機服務小費提醒（行程不含小費）

本行程團費不含導遊與司機服務小費，建議每位貴賓每日給予 台幣 NT$300 元 × 5 日 ＝ 共新台幣 1,500 元（於行程最後一日交予導遊統籌分配，感謝辛勞服務）。

泰國當地氣候、電壓與文化禮儀

  • • 電壓與插座：泰國電壓為 220V（台灣為110V）。手機、相機充電器多支援 100-240V 國際電壓（雙扁孔可直接插入），若攜帶吹風機或電捲棒請務必確認支援 220V。
  • • 天氣與衣著：12月為泰國涼季，白天氣溫約 25°C - 32°C 舒適晴朗，請準備夏季透氣衣物、防曬用品、太陽眼鏡，並隨身攜帶一件薄外套防遊覽車冷氣。
  • • 參觀大皇宮服裝規定：皇宮與佛寺對服裝要求嚴格，不可穿無袖上衣、露肩背心、短褲、破洞牛仔褲、緊身瑜珈褲及拖鞋，請著有袖上衣搭配長褲或過膝長裙。
  • • 敬重皇室與僧侶：泰國人極為敬重皇室與佛教，切勿評論泰國皇室；女性請勿觸碰僧侶身體或衣物；拍攝佛像時請保持恭敬（拍樹中佛頭時人不可高於佛頭）。
