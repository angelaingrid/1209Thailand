❖二、五日精選行程與餐食安排 全程無購物站壓力

DAY 1 2026/12/09 (三) 高雄小港機場 → 曼谷素萬那普機場 → 最接地氣 Save One Go 夜市

【景點介紹】Save One Go 夜市：曼谷近年超人氣的在地人夜市！匯集道地泰式平價小吃、炭烤海鮮、泰式奶茶與潮流服飾，物價親民、氛圍輕鬆，是第一晚體驗曼谷夜生活與大啖美食的最佳去處。

早餐：敬請自理
午餐：機上簡餐
晚餐：樂來順或文華 中泰式合菜 (餐標 THB 350)
住宿：Avani Sukhumvit Bangkok
DAY 2 2026/12/10 (四) 大皇宮與鄭王廟 → ICONSIAM 室內水上市場 → 河畔遊船晚宴

【景點介紹】大皇宮與鄭王廟：匯聚泰國皇室建築藝術巔峰的金碧輝煌宮殿；隨後造訪擁有「泰國艾菲爾鐵塔」美譽的鄭王廟。ICONSIAM 暹羅天地：曼谷頂級河岸地標百貨，安排逛逛冷氣開放的「SOOKSIAM 室內水上市場」。昭披耶公主號遊船晚宴：搭乘豪華遊輪夜遊昭披耶河，享用自助餐並欣賞兩岸皇宮寺廟夜景。

早餐：飯店內用
午餐：方便逛街 敬請自理
晚餐：昭披耶公主號自助餐 (餐標 THB 750)
住宿：Avani Sukhumvit Bangkok
DAY 3 2026/12/11 (五) 大城世界遺產 → 瑪哈泰寺(樹中佛頭) → 柴瓦塔那蘭寺+泰服體驗 → 大城大頭蝦市場 → 邦巴茵夏宮 → Big C 超市大採購

【景點介紹】瑪哈泰寺（樹中佛頭）：受菩提樹根溫柔包覆的慈祥佛頭，為泰國七大奇景之一（※註：參觀樹中佛如欲拍照留念，提醒您影中人身高不可高於佛頭，以免對神明造成不敬！）。柴瓦塔那蘭寺＋泰服體驗：換上華麗傳統泰服漫步於紅磚佛塔群間。大城大頭蝦市場＆邦巴茵夏宮：品嚐現烤爆膏大頭蝦，走訪皇室避暑行宮，晚上至 Big C 超市採買伴手禮。

早餐：飯店內用
午餐：方便逛街 敬請自理
晚餐：方便逛街 敬請自理

【景點介紹】丹能莎朵水上市場（含手搖船）：搭乘傳統手搖船穿梭於運河水道，體驗與船家交易熱帶水果的樂趣。美功鐵道市場＆網美泡泡屋：見證火車鳴笛駛過攤販棚架收合奇觀（※註：菜市場鐵路火車之旅，常有誤點，敬請耐心等候）；午後造訪水上漂浮「網美泡泡屋咖啡廳」。四面佛＆中央百貨：前往曼谷四面佛祈福並逛 Central World 商圈。

❖ 三、泰國入境與行前必讀注意事項

📲 泰國電子入境卡申報（TDAC）— 出發前必填 https://tdac.immigration.go.th/arrival-card/#/home

入境泰國前需事先於線上完成泰國數位入境卡（TDAC）免費申報，請務必於抵達泰國前 72 小時（3天）內準備護照、去回程航班（CI839 / CI840）及飯店名稱（Avani Sukhumvit Bangkok Hotel）上網填寫，完成後請將產生的 QR Code 確認信手機截圖或列印，於曼谷機場通關時出示查驗。

🛃 入境海關與攜帶現金提醒

• 泰國海關隨機抽查：每人須準備 20,000 泰銖、每個家庭 40,000 泰銖（等值美金、台幣現金亦可，不可用信用卡代替）。
• 攜帶現金上限：出入境攜帶現金勿超過等值台幣拾萬元。

🧳 行李重量與安檢規定

• 託運行李：每人限重 23 公斤（1件）；液體類、噴霧及尖銳物品請放置於託運行李中。
• 手提行李：每人限重 7 公斤；手機電池、相機電池、行動電源等鋰電池及打火機（限1個），務必放置隨身行李（不可託運）。

🔌 電壓插座與天氣衣著

• 電壓 220V：手機充電器多支援 100-240V 國際電壓（雙扁孔通用），高功率電器請確認支援 220V。
• 氣候炎熱：白天約 25°C - 32°C，請注意防曬並多補充水分，建議隨身帶薄外套防遊覽車冷氣。

🛕 景點參觀與文化禮儀

• 大皇宮服裝：需著有袖上衣、長褲或過膝長裙（禁無袖、短褲、破洞褲及拖鞋）。
• 敬重神明皇室：拍樹中佛頭時人不可高於佛頭；女性不可觸碰僧侶；切勿評論泰國皇室。
